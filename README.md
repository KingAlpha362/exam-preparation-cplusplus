# C++ Revision Workbook

A collection of C++ revision snippets for control flow, linked nodes, playlists, and shop calculations.

## ✨ Highlights

- Exercises are organised as separate `.cpp` files.
- Topics include conditions, loops, switch statements, and node traversal.

## 🚀 Getting started

With a C++ compiler installed, compile one exercise at a time:

```sh
g++ -std=c++17 "Music Playlist.cpp" -o exercise
./exercise
```

On Windows PowerShell, use `-o exercise.exe` and run `.\exercise.exe`. Each exercise is separate; do not link every source file into one executable.
